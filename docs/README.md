## Documentation Standards

### File Naming Convention

- Core modules: `MODULE_[NAME].md`
- HR-specific: `HR_[TYPE].md`
- API docs: `[MODULE]_API.md`
- Integration: `[MODULE]_INTEGRATION.md`
- Security: `[MODULE]_SECURITY.md`

### Documentation Structure

Each module documentation includes:

1. **Purpose & Audience** - Who this is for
2. **Features Overview** - What the module does
3. **Technical Details** - How it works
4. **User Guide** - How to use it
5. **API Reference** - Integration points
6. **Security** - Access controls and compliance
